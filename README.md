# olist-customer-segmentation
Customer segmentation project using the Olist Brazilian E-Commerce Public Dataset and machine learning.

## Project Overview
This project focuses on developing a customer segmentation solution
for Olist, a Brazilian e-commerce marketplace. It uses historical
transaction data to identify customer groups based on purchasing
behaviour and customer experience.

## Business Problem
Olist needs a more structured understanding of customer purchasing
patterns to support targeted marketing, customer retention and
customer experience decisions.

## Dataset
Brazilian E-Commerce Public Dataset by Olist (2016–2018).

Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Objectives
- Develop meaningful customer segments.
- Apply Recency, Frequency and Monetary (RFM) analysis.
- Implement K-Means clustering.
- Evaluate cluster quality and interpretability.
- Develop a Power BI customer segmentation dashboard.
- Provide actionable business recommendations.
